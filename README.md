TargetClicker для Warface Arena

TargetClicker — небольшое приложение для Windows, которое автоматически наводит прицел на белые шары в браузерной тренировке Warface Arena:

**https://wfarena.ru/training**

Приложение захватывает изображение выбранной области экрана, распознаёт шары и перемещает мышь или прицел за пользователя. При желании можно включить автоматический клик после наведения.

## Скачать и запустить

1. Открой раздел **Releases** этого GitHub-репозитория.
2. В последнем релизе скачай `TargetClicker.exe`.
3. Запусти файл на Windows 10 или Windows 11.
4. Если приложение сообщает об отсутствии WebView2 Runtime, установи [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) и запусти приложение снова. .NET отдельно устанавливать не нужно.

## Быстрый старт

1. Открой [wfarena.ru/training](https://wfarena.ru/training) в браузере и выбери тренировку с белыми шарами.
2. В TargetClicker нажми **Выбрать область** и выдели прямоугольником игровое поле тренировки. Не включай в область таблицу, счётчики и элементы страницы.
3. Если тренировка полноэкранная и браузер захватывает курсор, оставь включённым **Центральный прицел**. Выделенная область должна охватывать игровое поле целиком, чтобы её центр совпадал с прицелом.
4. Включи **Следить за шаром**, чтобы приложение само переводило прицел на найденную цель.
5. Для автоматического клика после наведения дополнительно включи **Стрелять после наведения**. Если нужна только помощь с наведением, оставь этот переключатель выключенным.
6. Вернись к вкладке тренировки и нажми `F8`, чтобы запустить помощника. Нажми `F8` ещё раз для остановки. Если `F8` занята, приложение покажет запасную комбинацию `Ctrl+F8`.

## Настройки

| Настройка | Что делает |
| --- | --- |
| **Центральный прицел** | Использует центр выбранной области как точку прицела. Подходит для полноэкранного режима с захваченным курсором. |
| **Следить за шаром** | Ищет белый шар в выбранном поле и ведёт к нему прицел. |
| **Стрелять после наведения** | Включает клик после того, как прицел навёлся на найденный шар. Доступно при включённом слежении. |

## Если не работает

- **Не видит шар.** Проверь, что выделено именно игровое поле и шар находится внутри него. Попробуй заново выбрать область.
- **Прицел смещён.** В полноэкранном режиме включи **Центральный прицел** и выдели всё игровое поле от края до края. При оконном режиме отключи этот параметр, если курсор свободно перемещается.
- **F8 не запускает помощника.** Посмотри подсказку внизу окна: если клавиша занята другой программой, там будет `Ctrl+F8`. Также помощник не запустится, пока не выбрана область.
- **Окно пустое или не открылось.** Установи или обнови [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), затем перезапусти TargetClicker.

## Сборка из исходников

Для разработки нужны Windows и .NET 10 SDK. WebView2 Runtime требуется для запуска интерфейса.

Открой PowerShell в корневой папке проекта — рядом с `TargetClicker.csproj` — и выполни:

```powershell
dotnet run --project .\TargetClicker.csproj
```

Чтобы собрать один EXE для Windows x64, выполни в той же папке одной строкой:

```powershell
dotnet publish .\TargetClicker.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:IncludeAllContentForSelfExtract=true -p:DebugType=None -p:DebugSymbols=false -o .\single-exe
```

Файл появится в `single-exe\TargetClicker.exe`. .NET входит в EXE; WebView2 Runtime устанавливается отдельно.

- `Program.cs` — запуск приложения.
- `TargetClicker.csproj` — настройки проекта и зависимость WebView2.
- `README.md` — эта инструкция.

Приложение создано для вкладки тренировки Warface Arena и работает по изображению экрана. Сайт тренировки может учитывать клики и показывать результат в соответствии со своими настройками и правилами аккаунта.
