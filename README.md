# TargetClicker

Windows-приложение для автоматического наведения на белые шары во вкладке тренировки **Warface Arena**: [wfarena.ru/training](https://wfarena.ru/training).

TargetClicker анализирует изображение выбранной области страницы, находит шары и перемещает прицел за пользователя. В режиме слежения можно отдельно включить клик после наведения. Программа предназначена для браузерной тренировки на этой странице.

> Сайт может учитывать клики и результаты согласно настройкам тренировки и аккаунта.

## Возможности

- Распознавание белых и светло-серых шаров в тренировке на wfarena.ru.
- Выбор области экрана с вкладкой тренировки.
- Режим центрального прицела для полноэкранной тренировки с захваченным курсором.
- Слежение за шаром и автоматическое наведение.
- Необязательный клик после наведения.
- Глобальная клавиша запуска и остановки: `F8` (если занята — `Ctrl+F8`).
- Современный HTML/CSS-интерфейс в окне приложения на WebView2.

## Быстрый старт

1. Открой [wfarena.ru/training](https://wfarena.ru/training) в браузере и запусти тренировку с белыми шарами.
2. Запусти `TargetClicker.exe`. Для интерфейса нужен [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), обычно он уже установлен вместе с Microsoft Edge.
3. Нажми **Выбрать область** и выдели игровое поле тренировки. В полноэкранном режиме с захваченным курсором включи **Центральный прицел** и выдели поле целиком.
4. Включи **Следить за шаром**. Для автоматического клика по наведённой цели также включи **Стрелять после наведения**.
5. Вернись во вкладку тренировки и нажми `F8`, чтобы запустить или остановить помощника. Если F8 занята, используй `Ctrl+F8`.

## Режимы

- **Центральный прицел** — считать, что прицел тренировки находится в центре выбранной области. Подходит для полноэкранного режима, когда браузер захватывает курсор.
- **Следить за шаром** — найти белый шар во вкладке тренировки и переводить прицел на него.
- **Стрелять после наведения** — кликнуть по шару после совмещения прицела.

Сначала попробуй слежение без автоматической стрельбы. Выделяй игровое поле страницы, не таблицу рейтинга и остальные элементы сайта. Если `F8` занята другим приложением, TargetClicker покажет `Ctrl+F8`.

## Запуск из исходников

Требования:

- Windows 10 или новее.
- .NET 10 SDK.
- WebView2 Runtime.

Из корня репозитория выполни:

```powershell
dotnet run --project tools/TargetClicker/TargetClicker.csproj
```

## Сборка одного EXE

Из корня репозитория:

```powershell
dotnet publish tools/TargetClicker/TargetClicker.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:IncludeAllContentForSelfExtract=true `
  -p:DebugType=None -p:DebugSymbols=false `
  -o tools/TargetClicker/single-exe
```

В результате получится `tools/TargetClicker/single-exe/TargetClicker.exe`. .NET включён в файл; WebView2 Runtime устанавливается отдельно.
